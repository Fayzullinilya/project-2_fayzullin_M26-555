Команды для управления таблицами:

- ``create_table <table> <column1:type> <column2:type> ...`` — создаёт таблицу с именем `<table>` и колонками `<column1>`, `<column2>`, … соответствующих типов `<type>` = `{'int', 'str', 'bool'}`.  
  Наименования таблиц и колонок могут содержать только латинские буквы `['A-Z', 'a-z']`, цифры `['0-9']`, символ подчёркивания `['_']` и не могут начинаться с цифры.  
  Если колонка `id` не задана, то она создаётся автоматически с типом `'int'`.

  Пример: ``create_table users name:str age:int is_active:bool``

- ``drop_table <table>`` — удаляет таблицу с именем `<table>`.  
  Пример: ``drop_table users``

- ``list_tables`` — выводит список существующих таблиц.

Пример работы с таблицаи: https://asciinema.org/a/raspyq6dHC6YYP4T


Команды для работы с данными: 

- ``insert into <имя_таблицы> values (<значение1>, <значение2>, ...)`` - создает запись в таблице. Все колонки таблицы считаются обязательными. ID генерируется автоматически. Значения флагов могут передаваться как "true"/"false" или "0"/"1". Если текст содержит запятую его необходимо заключить в кавычки.
  
  Пример: ``insert into users values ("Sergei", 28, true)``

- ``select from <имя_таблицы> [where <столбец1> = <значение>, [<столбец2> = <значение>]...]- прочитать записи по условию. Поддерживается только условие '='. Если условие WHERE не задано - выводится вся таблица. Список условий задается через запятую. Если значение содержит запятую его необходимо заключить в кавычки.

  Пример: ``select from users where age = 28, is_active = true``

- ``update <имя_таблицы> set <столбец1> = <значение1>, [<столбец2> = <значение2>...] where <столбец1> = <значение1>, [<столбец2> = <значение2>...]`` - обновляет значения указанных в SET колонок в строках, удовлетворяющих условию WHERE. Если совпадений нет, или условие WHERE не куазано, данные не обновляются. Списки присвоений и условий задаются через запятую. Если значение или условие содержат запятую их необходимо заключить в кавычки.

  Пример: ``update users set age = 29, is_active = false where name = "Sergei", is_active = true``

- ``delete from <имя_таблицы> where <столбец1> = <значение1>, [<столбец2> = <значение2>]`` - удаляет записи соответствующие условию WHERE. Если условие не задано, уделение не выполняется. Список условий задается через ','

  Пример: ``delete from users where ID = 1``

- ``info <имя_таблицы>`` - выводит информацию о таблице.
